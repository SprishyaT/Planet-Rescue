# Planet Rescue (v1.00)
An environmentally friendly planet saving game made with Flutter.

## What is Planet Rescue?
Planet Rescue is a planet saving game built completely with Flutter where users complete eco-friendly tasks to save different types of planets and earn badges.

## How Do Users Play?

### Log In/Sign Up
When users enter the game, regardless of whether it is their first time or not, they will be prompted to fill in their email/chosen username and password correctly. There is no "Forgot Password" option currently, but there will be one coming soon. Signing in with Google and other third parties will also be available coming soon.

### Tabs
There are 4 different tabs users can navigate through after they log in or sign up- Planets, Tasks, Badges, and Settings. An account and profile page is coming soon.

- **Planets:** This tab displays the name and picture of the planet the user is on with a greeting to them. This tab is also the main tab and the tab users start from after they log in or sign up.
- **Tasks:** This tab is made of 50 handcrafted environmentally-friendly tasks, with each planet's tasks. Users can switch between planets in this tab and can see the tasks they have completed (checked) and the ones they have not (unchecked).
- **Badges:** This tab contains 6 badges that users can earn, and a search box to help them find the badge they want.
- **Settings:** This tab consists of 3 different settings which users can set to their desired choice.

### Planets
There are 3 different planets users can complete- Landlock, Watercountry, and Populus.

- **Landlock:** This is a **Land** planet where users have to complete land-based missions to save it. Landlock is the easiest planet to complete for beginners, and it has **10** tasks.
- **Watercountry:** This is a **Water** planet where users have to complete water-based missions to save it. Watercountry is neither easy nor hard; it is best fit for Intermediates. It has **20** tasks.
- **Populus:** This is a **Human-based** planet where users have to complete tasks that help solve human-based issues to save it. Populus is the hardest and most advanced planet, and it has **30** tasks.

### Badges and Achievements
There are currently 5 badges that users are able to earn that belong in 2 different categories- Task Badges, which users earn by completing a certain amount of tasks, and Planet Badges, which they can earn if they rescue a certain amount of planets.

### Task Badges
- **Eco-Friendly:** Complete 5 Tasks
- **Environment Supporter:** Complete 15 Tasks
- **Nature Activist:** Complete 50 Tasks

### Planet Badges
- **Rookie Planet Helper:** Save 1 Planet
- **Pro Planet Saver:** Save 3 Planets

When a user completes a badge, they receive a pop-up congratulating them that they received it and stating the conditions to earn the badge, regardless of which tab they are on.

### Settings
There are 3 different settings that users can set:

- **Theme:** Users can switch between light and dark themes whenever they want to.
- **High Contrast:** To make the game more accessible, users can enable and disable high contrast mode to better suit them.
- **Font Size:** As another accessibility feature, this allows users to enlarge or shrink text size to whatever they feel comfortable with.

More settings are coming soon.
